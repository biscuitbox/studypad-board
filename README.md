# 스터디패드 만들기

2.8인치 ESP32 터치 보드(E32R28T)로 지뢰찾기·영어 단어·상식 퀴즈가 들어간 공부 단말기를 만드는 메이커 동아리 자료입니다.

- 사이트: https://biscuitbox.github.io/studypad-board/
- 보드 코드: [downloads/StudyPad.zip](downloads/StudyPad.zip)
- 케이스(단색 STL): [downloads/StudyPad_case.zip](downloads/StudyPad_case.zip) — 교탁 도우미(ES3C28P) 케이스와 같은 파일

| 페이지 | 내용 |
| --- | --- |
| `index.html` | 홈 — 소개, 만드는 순서, 앱 미리 보기, 준비물 |
| `setup.html` | 설치·업로드 가이드 — 아두이노 IDE, 보드 매니저, 라이브러리 매니저, 업로드, 안 될 때 |
| `slides.html` | 설치·업로드 가이드 슬라이드 (35장) — 교실 TV용. ← → 키, 스와이프, 아래 막대의 단계 바로 가기 |
| `apps.html` | 앱 사용법 |
| `mods.html` | 코드 고쳐 보기 미션 |

`shots/`의 `ide_*.png` 그림은 이해를 돕기 위해 다시 그린 IDE 화면입니다. 실제 캡처로 바꾸려면 같은 파일 이름으로 덮어쓰면 됩니다.
