코드 고쳐 보기

코드를 처음부터 쓰지 않아도 돼요. 이미 있는 코드에서 글자와 숫자만 바꿔도 내 기기가 돼요. 미션 1부터 순서대로 해 보세요. 업로드 방법을 잊었으면 설치·업로드 가이드 9~11단계를 다시 봐요.

고치기 전에미션 1 제목미션 2 단어미션 3 퀴즈미션 4 효과음미션 5 숫자 바꾸기미션 6 새 앱자주 나는 오류

고치기 전에 꼭

  1. 원본을 복사해 두어요. StudyPad 폴더를 통째로 복사해 StudyPad_원본 같은 곳에 두면, 망가져도 언제든 돌아갈 수 있어요.
  2. 고칠 곳은 찾기로 찾아요. 탭을 고른 뒤 Ctrl + F를 누르고 낱말을 입력하면 그 줄로 가요.
  3. 하나 고치고 → 업로드 → 확인. 여러 군데를 한꺼번에 고치면 오류가 어디서 났는지 찾기 어려워요.
  4. 잘못 고쳤으면 Ctrl + Z로 되돌려요. 저장은 Ctrl + S.

코드 문장부호 네 가지만 기억해요

  • "글자" 글자는 큰따옴표 두 개로 감싸요. 하나라도 빠지면 오류예요.
  • , 목록의 항목 사이에는 쉼표를 찍어요.
  • ; 한 문장이 끝나면 세미콜론을 찍어요.
  • { } 여는 괄호와 닫는 괄호는 꼭 짝이 맞아야 해요.

줄 앞에 //가 있으면 주석이에요. 사람이 읽으라고 쓴 설명이라서 보드는 무시해요.

1홈 화면 제목을 내 이름으로

홈 화면 맨 위의 스터디패드 글자를 바꿔 봐요. 가장 쉬운 미션이에요.

  1. StudyPad.ino 탭을 눌러요.
  2. Ctrl + F로 drawString("스터디패드"를 찾아요.
  3. 큰따옴표 안의 글자만 바꿔요. 따옴표는 지우면 안 돼요.
  4. 업로드하고 홈 화면을 확인해요.
  lcd.drawString("스터디패드", 10, 18);
  lcd.drawString("민준이의 패드", 10, 18);

글자가 □로 나오면 화면 글꼴에 없는 글자예요. 이 보드의 글꼴에는 자주 쓰는 한글 2,350자만 있어서 '똠', '뷁' 같은 글자나 이모지는 안 나와요. 다른 낱말로 바꿔요.

도전: 시작 화면의 "공부도 놀이도 한 손에"도 찾아서 나만의 문구로 바꿔 봐요.

2우리 반 영어 단어 넣기

영어 단어는 data_words.h 탭에 한 줄에 하나씩 들어 있어요.

// { 단어장, "영어", "뜻" },   단어장: 1 = 중학, 2 = 고등, 3 = 숙어
  { 1, "able", "할 수 있는" },
  { 1, "about", "~에 대하여, 약" },
  1. data_words.h 탭을 열고, Ctrl + F로 1. 중학 필수를 찾아요.
  2. 그 아래 아무 줄 끝에서 Enter를 눌러 새 줄을 만들어요.
  3. 모양을 똑같이 맞춰 새 단어를 써요. 줄 끝의 쉼표까지!
  4. 업로드하고 영어 단어 → 중학 → 카드 학습에서 찾아봐요.
  { 1, "able", "할 수 있는" },
  { 1, "microbit", "마이크로비트" },
  { 1, "soldering", "납땜" },
  { 1, "about", "~에 대하여, 약" },
  • 철자 쓰기에는 알파벳 소문자로만 된 12글자 이하 단어만 나와요.
  • '하루 10단어'는 파일에 적힌 순서대로 10개씩 묶어요. 중간에 끼워 넣으면 그 뒤 일차의 단어가 한 칸씩 밀려요. 이미 공부한 단어를 건드리기 싫으면 단어장 맨 끝에 넣어요.
  • 단어는 모두 합쳐 2,000개까지 넣을 수 있어요.

3상식 퀴즈 문제 만들기

퀴즈 문제는 data_quiz.h 탭에 있어요. 문제 하나는 분야 번호, 문제, 보기 4개, 해설로 되어 있어요.

  { 0, "사람의 몸에서 가장 큰 기관은 무엇일까요?",
    { "피부", "간", "폐", "뇌" },
    "피부는 몸 전체를 덮고 있어 넓이와 무게 모두 가장 큰 기관이에요." },
번호분야
0과학
1한국사
2세계·지리
3우리말
4생활·사회
5예술·체육
  1. 정답은 항상 첫 번째 보기에 써요. 화면에서는 보기 순서가 저절로 섞여요.
  2. 문제는 45글자, 해설은 60글자 정도까지가 화면에 잘 들어가요.
  3. H₂O의 작은 숫자 같은 특수 글자는 안 나와요. H2O, cm3처럼 써요.
  4. 마지막 문제 아래, }; 바로 위에 넣어요.
  { 0, "물이 얼면 부피는 어떻게 될까요?",
    { "커진다", "작아진다", "그대로다", "없어진다" },
    "물은 얼음이 되면 부피가 약 9% 커져요. 그래서 얼음이 물에 떠요." },
};

모둠 활동: 한 모둠이 한 분야를 맡아 5문제씩 만들고, 보드를 바꿔 서로 풀어 봐요. 분야 이름은 QUIZ_CATS 줄에서 바꿀 수 있어요. 예: "생활·사회" → "우리 학교"

4효과음 바꾸기 — 소리의 높낮이

소리는 진동수(1초에 떨리는 횟수, 단위 Hz)가 클수록 높아요. 효과음은 hw.cpp 탭에 {진동수, 길이(ms), 진동수, 길이, …} 모양으로 적혀 있어요. 진동수가 0이면 쉼표예요.

// 이겼을 때 나는 소리: 도 미 솔 도~ (쉼) 솔 도~~
  static const uint16_t WIN[] = { 523, 100, 659, 100, 784, 100, 1047, 250, 0, 60, 784, 100, 1047, 300 };
  ...
    case SFX_WIN:   playMelody(WIN, 7); break;   // 7 = 음표 개수
음도레미파솔라시높은 도
진동수 (Hz)5235876596987848809881047
  1. hw.cpp 탭에서 WIN[]을 찾아요.
  2. 숫자를 바꿔 나만의 승리 소리를 만들어요. 예: 솔솔라라솔솔미 = 784, 200, 784, 200, 880, 200, 880, 200, 784, 200, 784, 200, 659, 400
  3. 음표 개수가 바뀌었으면 playMelody(WIN, 7)의 숫자도 바꿔요. 위 예시는 7개예요. (최대 32개)
  4. 업로드하고 지뢰찾기를 깨 보거나, 영어 단어 퀴즈를 다 맞혀서 들어 봐요.

과학 연결: 진동수를 2배로 하면 한 옥타브 높은 소리가 나요(523 → 1047). 같은 음의 진동수를 바꿔 가며 들어 보고, 사람이 듣기 좋은 높이를 찾아봐요.

5숫자 바꿔서 규칙 바꾸기

하루에 외울 단어 수

app_words.cpp 탭 위쪽에 있어요.

const int DAY_SIZE = 10;     // 하루에 외울 단어 수
const int PASS_SCORE = 8;    // 테스트 통과 점수 (10개 중)

DAY_SIZE를 바꾸면 일차마다 묶이는 단어가 달라져서 진도가 섞여요. 바꾼 뒤에는 설정 → 기록 지우기로 처음부터 시작하는 게 좋아요.

지뢰찾기 난이도

app_minesweeper.cpp 탭의 LEVELS예요. 순서대로 이름, 가로 칸 수, 세로 칸 수, 칸 크기(픽셀), 지뢰 수예요.

  { "쉬움",   10, 12, 24, 14 },
  { "보통",   10, 12, 24, 22 },
  { "어려움", 12, 14, 20, 35 },

화면에 들어가야 해요

  • 가로 칸 수 × 칸 크기 ≤ 240, 세로 칸 수 × 칸 크기 ≤ 288
  • 가로 × 세로 칸 수는 168(12 × 14)을 넘으면 안 돼요.
  • 지뢰 수는 전체 칸 수보다 10개 이상 적어야 해요.

예: 지뢰를 50개로 늘린 '지옥' 난이도 → { "지옥", 12, 14, 20, 50 }, 로 바꿔 봐요.

앱 색깔

ui.h 탭의 UI_RGB(빨강, 초록, 파랑) 숫자(0~255)를 바꾸면 홈 화면 앱 색이 바뀌어요.

static const uint16_t C_MINE  = UI_RGB(84, 98, 122);    // 지뢰찾기 색

6도전: 새 앱 만들기

app_reaction.cpp(반응 속도)는 새 앱을 만들 때 따라 하라고 넣어 둔 예제예요. 맨 위 설명을 읽고 아래 순서대로 해 봐요.

  1. IDE 오른쪽 위 탭 줄의 ⋯ → 새 탭을 눌러 app_my.cpp를 만들어요.
  2. app_reaction.cpp의 내용을 전부 복사(Ctrl+A, Ctrl+C)해서 새 탭에 붙여 넣어요.
  3. 새 탭에서 void appReaction()을 void appMy()로 바꾸고, 화면 글자를 내 앱에 맞게 고쳐요.
  4. apps.h 탭 맨 아래에 void appMy(); 한 줄을 넣어요.
  5. StudyPad.ino 탭의 APPS[] 목록 맨 아래에 한 줄을 넣어요. 홈 2쪽에 내 앱이 생겨요.
  // ---- 2쪽 : 학생들이 만든 앱을 여기에 추가해요 ----
  { "반응 속도", C_BAD,   iconReact, appReaction },
  { "내 앱",     C_OK,    iconReact, appMy },
};

앱의 기본 모양은 화면 그리기 → 반복: 터치 읽기 → 처리 → ◀를 누르면 끝이에요. 예제 코드의 주석을 따라 읽으면 어떤 줄이 무슨 일을 하는지 알 수 있어요.

자주 나는 오류

expected '}' before … / expected ',' or ';' before …

까닭
쉼표, 세미콜론, 괄호가 빠졌어요. 오류 줄 번호의 바로 윗줄을 먼저 봐요.
해결
방금 고친 줄을 위아래 줄과 비교해서 모양을 똑같이 맞춰요.

missing terminating " character

까닭
큰따옴표 하나가 빠졌어요.
해결
글자 앞뒤에 "가 두 개 있는지 확인해요.

'appMy' was not declared in this scope

까닭
apps.h에 void appMy();를 안 넣었거나, 이름 철자가 달라요.
해결
세 군데(새 탭, apps.h, APPS[])의 이름이 대문자까지 똑같은지 봐요.

너무 많이 고쳐서 뭐가 틀렸는지 모르겠어요

해결
복사해 둔 원본 폴더에서 그 탭 파일만 다시 가져오거나, 홈에서 StudyPad.zip을 새로 내려받아요.
